# 05 · 六爻纳甲

主线典籍：汉·京房纳甲为源，《火珠林》（托名麻衣道者）立成法，明《增删卜易》（野鹤老人）、《卜筮正宗》（王洪绪，清）、《易隐》为集大成。
用途：**单件具体事的成败、应期、过程形态**。不用于断一生格局。

## ⚠ 先读：脚本的可用边界

`scripts/engine/liuyao.js` 只算得**卦名、爻象、动爻**这三项可信；它的「六亲」「世应」两层是**简化实现，不可用于判断**：

| 问题 | 表现 | 正确做法 |
|---|---|---|
| 无卦宫概念 | 全脚本没有"卦宫"，世应标注为「（简化）」 | 世应必须按下方口诀自行定 |
| 六亲取错参照 | 用**日干**作"我" | 纳甲六亲以**卦宫五行**为"我" |
| 六亲命名错 | 输出「比肩／食神／偏财／印绶」等**十神名** | 正名为父母／兄弟／子孙／妻财／官鬼 |

因此本 skill 的规矩是：**脚本起卦，方向为手装。** 且必须在输出中说明六亲与世应系手工推得，不是脚本给的。

## 一、装卦六步

### 第 1 步 起卦
三枚铜钱摇六次（自下而上），或按时间/数字起。脚本：`node liuyao.js 012013 问题`（0=阳不动，1=阴不动，2=阳动，3=阴动）。

### 第 2 步 纳甲（装地支天干）

口诀（《卜筮正宗》）：「乾金甲子外壬午，震木庚子外庚午，坎水戊寅外戊申，艮土丙辰外丙戌，巽木辛丑外辛未，离火己卯外己酉，兑金丁巳外丁亥，坤土乙未外癸丑。」

| 经卦 | 内卦（初→三） | 外卦（四→上） |
|---|---|---|
| 乾 | 甲 子、寅、辰 | 壬 午、申、戌 |
| 震 | 庚 子、寅、辰 | 庚 午、申、戌 |
| 坎 | 戊 寅、辰、午 | 戊 申、戌、子 |
| 艮 | 丙 辰、午、申 | 丙 戌、子、寅 |
| 巽 | 辛 丑、亥、酉 | 辛 未、巳、卯 |
| 离 | 己 卯、丑、亥 | 己 酉、未、巳 |
| 兑 | 丁 巳、卯、丑 | 丁 亥、酉、未 |
| 坤 | 乙 未、巳、卯 | 癸 丑、亥、酉 |

规律：**阳卦（乾震坎艮）顺行，只纳阳支；阴卦（坤巽离兑）逆行，只纳阴支。** 天干本身不参与吉凶，只用于取数。

### 第 3 步 定卦宫

八宫五行：乾兑属金、震巽属木、坎属水、离属火、坤艮属土。

寻宫诀（《卜筮正宗》一系）：
> 一二三六外卦宫，四五游魂内变更，归魂内卦是本宫。

即：世爻在初／二／三／六爻时，卦宫即**外卦**所属之宫；世在四、五爻及游魂卦时，取**内卦变卦**之宫；归魂卦取**内卦**之宫。

### 第 4 步 定世应

安世应诀：「八卦之首世六当，以下初爻轮上扬，游魂八宫四爻立，归魂八卦三爻详。」

| 卦序 | 世爻位置 |
|---|---|
| 八纯（本宫首卦） | 六爻 |
| 一世卦 | 初爻 |
| 二世卦 | 二爻 |
| 三世卦 | 三爻 |
| 四世卦 | 四爻 |
| 五世卦 | 五爻 |
| 游魂卦 | 四爻 |
| 归魂卦 | 三爻 |

**应爻＝与世爻相隔两爻**：世1→应4、世2→应5、世3→应6、世4→应1、世5→应2、世6→应3。

（另有对偶口诀可交叉校验：「天同二世天变五，地同四世地变初，本宫六世三世异，人同游魂人变归」。）

### 第 5 步 装六亲

以**卦宫五行**为"我"，与各爻地支五行比较：

| 关系 | 六亲 |
|---|---|
| 生我者 | 父母 |
| 我生者 | 子孙 |
| 克我者 | 官鬼 |
| 我克者 | 妻财 |
| 比和者 | 兄弟 |

### 第 6 步 配六神

口诀：「甲乙起青龙，丙丁起朱雀，戊日起勾陈，己日起腾蛇，庚辛起白虎，壬癸起玄武。」
**由初爻起，依次上行**，循环为：青龙 → 朱雀 → 勾陈 → 螣蛇 → 白虎 → 玄武。

## 二、用神取用表

**取错用神则全卦皆废。** 这是六爻的第一步也是最关键一步。

| 所问之事 | 用神 | 备注 |
|---|---|---|
| 求财、买卖、妻（男问） | 妻财 | |
| 事业、职位、官司、夫（女问）、疾病之病 | 官鬼 | |
| 父母、长辈、师长、文书、房产、学历 | 父母 | |
| 子女、下属、平安、医药（治病的药） | 子孙 | |
| 兄弟、同辈、合伙人、竞争者 | 兄弟 | |
| 自身状态 | 世爻 | 世为求测人本人 |
| 对方／所问之事 | 应爻 | |

**双用神**时（如同时问财与职位），分主次，不可混断。

## 三、断卦要点

1. **先看用神旺衰**：月建（月令）与日辰对用神的生克。用神临月建／日辰为旺，被月克为月破、被日冲为日破。
2. **再看动爻**：动则变。动爻对用神生扶或克害；变爻对动爻有**回头生／回头克**。
3. **看旬空**：用神旬空则事多不实或待空亡填实之期；动而空者待填实。
4. **看六冲六合**：六冲卦主散、主速，六合卦主成、主缓。用神逢冲要看是否衰而受冲（散）还是旺而受冲（动）。
5. **看世应关系**：应生世、应合世为得助；应克世、应冲世为受阻。世空则己方心不实。
6. **应期**：以用神旺相之时、值日值月之年月日，或用神被冲被合而动的时点为应。**先定用神，再定应期，不得倒推。**

## 四、与梅花的差异

| | 六爻纳甲 | 梅花易数 |
|---|---|---|
| 起卦 | 摇卦，或按爻象 | 数字、时间、方位、外应 |
| 核心 | 装卦后的用神与六亲体系 | 体用五行生克 |
| 强度 | 体系严密，可断细节与应期 | 快速，重当下气机 |
| 弱项 | 装卦繁琐，取用神易错 | 细节定位弱，主观性大 |

问事**优先六爻**；只想快速看个大概或用户随口一问时才用梅花。

## 五、自检问题

1. 我的卦宫是怎么定的？世应位置与卦宫序对得上吗？
2. 六亲是以**卦宫**为"我"装的，还是又跟着脚本的日干口径跑了？
3. 用神取对了没有？如果所问之事跨两个范畴，我分了主次吗？
4. 用神是旺是衰？月建与日辰分别对它做了什么？
5. 我的应期是从用神推出来的，还是先有结论再找依据？
