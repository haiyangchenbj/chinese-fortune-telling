# 02 · 调候扶抑派（滴天髓 · 穷通宝鉴）

主线典籍：《滴天髓》（任铁樵《滴天髓阐微》注本）、《穷通宝鉴》（余春台编，徐乐吾评注；原名《栏江网》）。
入手处：**日主状态与寒暖燥湿**。用途：定喜忌、断具体事宜、判断一生成就的实际难易。

与格局派的根本差异见 `00-schools-and-sources.md`。**两派常给出相反方向**，不得无标注混用。

## 一、滴天髓的四条主干

**寒暖燥湿（调候）**
> 「天道有寒暖，发育万物，人道得之，不可过也。地道有燥湿，生成品汇，人道得之，不可偏也。」

亥子丑月生者偏寒，需火暖局；巳午未月生者偏燥，需水润局。不足为"过/偏"，是首要的取用依据。

**衰旺真机**
> 「能知衰旺之真机，其于三命之奥，思过半矣。」

旺衰不是数五行个数，而是看得令、得地、得生、得助四项的合力，以及有无克泄耗的牵制。

**源流与流通**
> 「何处起根源，流到何方住，机括此中求，知来亦知去。」

看全局气机从哪里来、到哪里去。流通者气象好；壅塞者虽有力量而难以发挥。这是判断"能否顺利"的关键，也是格局派较少涉及的角度。

**通关**
> 「关内有织女，关外有牛郎，此关若通也，相邀入洞房。」

两神相战（如金木相战、水火相战）时，取其间的通关之神（金木战用土／水通关，水火战用木通关）。通关之神往往比扶抑用神更能解释实际境遇。

## 二、用神五法（取用顺序）

| 法 | 触发条件 | 取法 |
|---|---|---|
| 调候 | 寒暖燥湿明显偏枯 | 取暖局/润局之神，优先于扶抑 |
| 扶抑 | 日主明显偏强或偏弱 | 强者抑之（克泄耗），弱者扶之（印比） |
| 通关 | 局中两神相战 | 取居中通关之神 |
| 病药 | 局中有明显"病"（某神过旺或冲突） | 取去病之"药"（见 `01-bazi-geju.md` 第四节） |
| 专旺／从格 | 一行独旺或日主无根而从势 | 顺势不逆，**不再论扶抑** |

顺序不是教条：**调候急者先调候**（穷通宝鉴所谓"急"），否则扶抑做得再准也难见成效。

## 三、穷通宝鉴的用法：按十干×十二月查用神

《穷通宝鉴》本质是一张**十干在十二月的喜忌表**。以乙木为例：

| 乙木生于 | 主用 | 说明 |
|---|---|---|
| 寅月（孟春） | 丙、癸 | 尚寒需丙，土燥需癸 |
| 卯月（仲春） | 丙、癸 | 同上，癸可少 |
| 辰月（季春） | 癸、丙 | 先癸后丙 |
| 巳月（孟夏） | 癸 | 火旺，专用癸水润之 |
| 午月（仲夏） | 癸、丙 | 癸为要，丙助木气 |
| 未月（季夏） | 癸、丙 | 润土为先 |
| 申月（孟秋） | 丙、癸、己 | 金旺克木，丙火制金 |
| 酉月（仲秋） | 癸、丙 | 秋水金，癸润丙暖 |
| 戌月（季秋） | 癸、辛 | 土燥木枯 |
| 亥月（孟冬） | 丙 | 寒木向阳 |
| 子月（仲冬） | 丙 | 专取丙火解冻 |
| 丑月（季冬） | 丙 | 寒土冻木，非丙不生 |

**用法纪律**：此表是**参照而非公式**。原文本身即按"透某干、藏某支"分情况讨论，不可见月即套。徐乐吾评注本提示：所列多为定式，须与格局、全局配合看。

**引擎对应**：`scripts/engine/bazi-analysis.js` 输出的「调候用神（穷通宝鉴）」与「忌神」即按此表计算，并标注「调候俱全／不全／缺某」。"缺"项是取喜用的关键依据。

## 四、强弱分级的读法

引擎输出五档：**极弱 / 偏弱 / 中和 / 偏强 / 极强**，并给出四项计分明细（月令、比劫、通根、印绶）。

| 档位 | 处置 |
|---|---|
| 极弱 | 首选印比生扶；若全局无根且财官势重，须考察是否构成从格 |
| 偏弱 | 扶抑取印比，但不排斥调候 |
| 中和 | 不再扶抑，转看流通与调候，格局层次由相神定（回到 `01`） |
| 偏强 | 取克泄耗；先看有无调候需求 |
| 极强 | 首选中和之神与泄秀；若一行独旺成专旺格，顺其势 |

**从格判定（滴天髓·从化）**：「从得真者只论从，从神又有吉和凶。」
从财、从杀、从儿（食伤）、从势。成立条件：日主全无根气（无印无比劫通根），且所从之神乘旺。**从格不成立而误判为从，是最常见的严重误判**——务必先查日主在四支有无藏干同党。

引擎输出的「格局：X（从格）」即为该判定，需人工复核"日主是否真的无根"。

## 五、穷通宝鉴与滴天髓的分工

- **《穷通宝鉴》给的是"该用什么"**——十干×十二月的喜忌，直接、可查。
- **《滴天髓》给的是"怎么用"**——气势、流通、通关、体用精神的辩证方法。

两者合起来才是完整的调候扶抑派。只查《穷通宝鉴》的表会陷入模式化；只谈《滴天髓》的理则落不到具体干支。

## 六、自检问题

1. 这个局的寒暖燥湿偏向是什么？调候是否有"急"？
2. 我的用神是调候取的、扶抑取的，还是通关取的？先说清哪一法。
3. 如果判了从格，日主在四支是否真的全无根？有无藏干同党被漏算？
4. 我用《穷通宝鉴》的表时，有没有核对透干与藏干的具体情况，还是直接套了月令？
5. 这个局的气机流通吗？壅塞在哪里？通关之神是谁？
