# 00 · 流派分野与典籍源流

本文件是整套判据的地基。**任何解读若不先定位流派，结论就不可复核**——这是本 skill 与娱乐化命理产品的分界线。

## 一、目录学坐标：什么算"正典"

清《四库全书总目》子部立「术数类」，下分七属，实际收书分六类：

| 属 | 收录代表 | 本 skill 是否覆盖 |
|---|---|---|
| 数学 | 《太玄》《元包》《潜虚》《皇极经世》 | 否（象数易学，不属命理） |
| 占候 | 《灵台秘苑》《开元占经》 | 否（天象占） |
| 相宅相墓 | 《宅经》《葬书》《青囊奥语》 | 否（本 skill 只做择吉，不做空间调理） |
| 占卜 | 《六壬大全》《灵棋经》《易林》《京氏易传》《卜法详考》 | ✅ 六爻、梅花、大六壬 |
| 命书相书 | 《李虚中命书》《星命溯源》《三命通会》 | ✅ 八字、紫微、七政四余 |
| 阴阳五行 | 《太乙金镜式》《遁甲演义》《禽星易见》《星历考原》《协纪辨方书》 | ✅ 奇门、择吉 |

这个坐标的实用价值：**它是一道排除器**。塔罗、太阳星座运势、生命灵数、水晶疗愈等等都进不了这个框架，因此本 skill 一律不做——不是因为"迷信程度不同"，而是因为它们不属于同一套学理传统，混进来会让判据无法追溯。

## 三、核心分野：格局派 vs 调候扶抑派

**这是本文件最重要的一条。**

| | 格局派 | 调候扶抑派 |
|---|---|---|
| 核心典籍 | 《渊海子平》《三命通会》《星平会海》《神峰通考》《子平真诠》 | 《滴天髓》《穷通宝鉴》 |
| 入手处 | **月令**——月令所藏当令之神为格 | **日主状态＋寒暖燥湿** |
| 用神定义 | 格局的顺逆成败（"有用之官不可伤，有用之财不可劫"） | 扶抑日主、调和气候 |
| 典型判语 | "伤官配印""财旺生官""建禄用官" | "身弱宜印比""冬生喜丙火调候" |
| 强项 | 分层级、断贵贱、体系严整 | 断具体事宜、寒暖偏差直观 |
| 弱项 | 对无格可取之局（如杂气、身强无制）交待不清 | 易模式化、机械套用 |

两派不矛盾，但**经常给出方向相反的结论**。例：日主弱而月令财旺，格局派可能取"财格配印"以成格，调候派可能主张专意扶身。

**处置规则**：
1. 一次解读**只用一派作主线**，另一派仅在明确需要时作补充，且必须标注"以下为调候派视角"。
2. 若两派结论冲突且都有理，**如实并陈冲突**，说明分歧来自方法论差异，不要抹平。
3. 选用依据要写出来：月令透干成格者优先格局派；月令无格可取而寒暖偏枯者优先调候派。

## 四、其他主要流派

| 流派 | 入手处 | 与本 skill 的关系 |
|---|---|---|
| 禄命派（古法） | 年柱为本，纳音为主 | 仅作源流理解，不作主线（《李虚中命书》一系） |
| 神煞派 | 神煞吉凶 | **辅助层**，不得作主判据。古籍本身即视神煞为"辅助、次要参考" |
| 盲派 | 地支做功、宾主体用 | 独立主线，见 `03-bazi-mangpai.md` |
| 新派（现代旺衰量化） | 五行力量计分 | **不作判据**：打分模型缺乏典籍依据，且各家权重互不相同 |

## 五、流派声明模板（输出必写）

> 本盘以 **{流派}** 为主线判定。依据：月令{辰}透{干}，成{格局}，故取格局派；
> 该派在本题上的首要判据是「{某条具体规则}」。
> 补充视角：调候派主张{一句话}，与主线{一致／存在分歧，分歧点在于……}。

缺了这段的分析直接判为不合格输出。

## 六、自检问题

1. 我这次的结论出自哪一派？能指到具体典籍或篇目吗？
2. 若换另一派，结论会不会反过来？如果会，我说明了分歧吗？
3. 我引用的是典籍的判**法**，还是只是借它的名字给一个现代结论背书？
4. 这个体系在四库术数类里归哪一属？如果归不进去，我为什么还在用它的框架？
