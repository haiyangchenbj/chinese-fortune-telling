# 12 · 合婚合盘与流年推断法

## 一、合盘的判断优先级

合婚不是把四柱逐项比对求个平均分。**按下列优先级依次判**，前一层的结论权重远高于后一层：

| 序 | 判断项 | 依据 |
|---|---|---|
| 1 | **夫妻宫（日支）关系** | 双方日支的合冲破害——最直接反映日常相处的质地 |
| 2 | **日主关系** | 双方日主的五行生克——反映彼此的给予与消耗 |
| 3 | **配偶星互见** | 男看财、女看官，看配偶星在对方盘中的状态 |
| 4 | **天干相合** | 尤其日干五合，主吸引与绑缚 |
| 5 | 其余柱位比照 | 年月时柱的同位关系，看家庭背景、外部环境的一致性 |
| 6 | 纳音 | **古法，权重最低**，可略谈不可作依据 |

**纳音为什么低**：纳音是禄命派古法（唐李虚中一系）的产物，子平法兴起后已退居辅助。合婚里若以纳音定成败，是本末倒置。引擎会输出纳音，可以用作谈资，**不要用作结论**。

## 二、各项判据表

### 夫妻宫（日支）

| 关系 | 判语 |
|---|---|
| 六合（子丑、寅亥、卯戌、辰酉、巳申、午未） | 相处融洽，易成 |
| 三合／半合（申子辰、亥卯未、寅午戌、巳酉丑） | 有共同基础，关系稳固 |
| 相冲（子午、丑未、寅申、卯酉、辰戌、巳亥） | 摩擦直接、节奏冲突，需明确磨合机制 |
| 相破（子酉、丑辰、寅亥、卯午、巳申、未戌） | 小事上反复消耗，不易察觉但持续 |
| 相害（子未、丑午、寅巳、卯辰、申亥、酉戌） | 恩中带怨，容易说不到一处 |
| 比和 | 同类相处，理解容易但缺互补 |

### 日主关系

| 关系 | 判语 |
|---|---|
| 一方生另一方（如癸水生乙木、乙木生丙火） | 有扶持力，被生者受益更明显 |
| 日主比和 | 性相近，易共鸣，也易同向犯错 |
| 一方克另一方 | 存在主导与被主导，需看有无关通关之神 |
| 相克且有通关 | 矛盾可转化，反成助力 |

**注意方向**：日主相生不等于"平等的好"。生者长期付出、受生者长期获益，这种不对称本身要如实指出。

### 配偶星

- **男命以财为妻**：正财为正妻、偏财为偏财（恋爱对象／非正式关系）。看财星是否被比劫夺、是否被冲合。
- **女命以官为夫**：正官为正夫、七杀为偏夫。看官星是否被伤官克、是否被冲合。

配偶星在**自己的盘里**（状态、位置、有无伤克）比在**对方盘里**更能说明问题——这是常被忽略的一点。

### 天干五合

甲己合土、乙庚合金、丙辛合水、丁壬合木、戊癸合火。
**日干相合**是合婚中最被看重的单项之一，主天然的吸引与牵绊；但也主"绑缚"——合而不化时，关系黏而难断，未必全是好事。

## 三、⚠ 引擎的合盘输出有三处需修正

`scripts/engine/marriage.js` 可用，但三处不可直接采信：

**1 · 评分口径窄，分数偏低属正常**

`calculateOverallScore` 只计入 **日主关系** 与 **年支关系** 两项；**月柱冲、夫妻宫合、配偶星全部不计**。所以分数只反映前两项，70 分不等于关系一般。**报分时必须说明口径**，或干脆不报分、只作分项陈述。

**2 · 地支关系表不完整**

引擎只覆盖**六合／三合／六冲**，缺**六破、六害、暗合**。

| 引擎未覆盖 | 补充表 |
|---|---|
| 六破 | 子酉、丑辰、寅亥、卯午、巳申、未戌 |
| 六害 | 子未、丑午、寅巳、卯辰、申亥、酉戌 |
| 暗合 | 支中藏干相合（如寅中甲与未中己） |

实例：某造 月支为 **辰**、日支为 **卯** → **卯辰相害**；若对方某柱见 **丑**，则与辰成 **丑辰破**。引擎都会报"无特殊合冲"。**这些必须人工补上**，因为它们常是关系里真正反复出问题的地方。

**3 · 建议文案模板有误**

无论实际有无天干相合，结论段都会输出「天干相合，感情纽带强」。**以「详细分析」区的数据为准，不要转述这句。**

## 四、合盘的输出纪律

1. **分项陈述，不给单一总分收口。** 或给分但必须标明口径。
2. **不判"能不能结婚"。** 命理上能呈现的是相处模式与磨合点，不是判决。
3. 出现冲、破、害时，**给出可操作的磨合方向**，而不是只报凶。
4. 涉及第三方（如已有伴侣之外的关系）时，不做介入性判断。

## 五、流年大运推断法

### 纲目关系

- **大运为纲**：管十年的整体气象与主题。
- **流年为目**：管一年内的具体事件。
- 判流年先看大运的气象，再看流年的引动。**孤立的流年好不能逆大运之势，孤立流年差也不必然破大运之吉。**

### 引动方式（流年落地的机制）

原局里静止的字，要靠流年大运来"引动"才会兑现。四种引动：

| 方式 | 机制 | 事件形态 |
|---|---|---|
| **冲** | 流年支冲原局某支 | 变动、迁移、关系破裂或重组 |
| **合** | 流年支与原局某支六合／三合 | 确定、缔结、留驻 |
| **值** | 流年支与原局某支相同（临太岁） | 该宫位之事凸显、被放大 |
| **刑害** | 流年支刑害原局某支 | 纠缠、内耗、拖而不决 |

**看流年不要只看流年干支对日主是什么十神，更要看它引动了原局的哪一柱**——被引动的柱位（年＝长辈、月＝父母兄弟与事业环境、日＝自身与配偶、时＝子女与晚年）决定事件发生在哪个领域。

### 十神在流年的作用

- 流年十神说明该年的**主题性质**（官杀年多压力与职位事，财年多金钱与务实，印年多文书与庇荫，食伤年多表达与产出，比劫年多同侪与竞争）。
- 但**十神的意义随格局喜忌变化**：同一个七杀，对身强有制者是晋升，对身弱无制者是压迫。**先定格局喜忌，再谈十神吉凶。**

### 换大运与交运年

- 交运前后一两年常是**变动的窗口**（环境、关系、职业的转换）。
- 大运分管的争议：一派主张**天干管前五年、地支管后五年**，一派主张**干支共管十年**。本 skill 采后者为主、前者作辅，并**在输出中说明这是流派差异**。
- 大运干支与本命四柱成冲合时，是判该运吉凶的关键，不要只看大运本身的十神。

### 空亡与应期

- 流年落**空亡**：事多虚而不实，或延后。
- **应期判断**：原局中有而未发之事（如有合无冲、有用神受制），待其**被引动之年**为应——留者待合、实者待冲、虚者待填实。
- **先定应期依据，再说结论**。不要先有结论再找年份。

## 六、自检问题

1. 合盘里我先看的是夫妻宫还是纳音？（必须是夫妻宫，纳音最末）
2. 引擎报"无特殊合冲"的柱位，我有没有按六破六害暗合表复核？
3. 我报分数了吗？报的话说明口径了吗？
4. 我有没有转述引擎那句无条件的「天干相合，感情纽带强」？
5. 谈流年时我是只说十神，还是同时指出它引动了原局哪一柱？
6. 换大运的年份我标出来了吗？变动的窗口提示了吗？
7. 大运干支分管的流派差异，我说了没有？
