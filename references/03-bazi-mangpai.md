# 03 · 盲派：做功与宾主体用

## 一、先说明来源性质

盲派是**民间口传体系**，主要靠师徒口授流传于盲人算命群体，长期无公开典籍。现今可见的成体系著作（如段建业一系）属**现代整理**，不在《四库全书》术数类的典籍序列里。

因此本 skill 对盲派采取如下立场：

- **作为独立视角保留**——它的问题意识和判法确实自成体系，且能解释一些子平格局派讲不清的盘。
- **引用时必须标注其非典籍来源**，不得与《子平真诠》《滴天髓》等量齐观，也不得说"古法云"。
- **不作主线的默认选择**，只在格局派／调候派都讲不通时启用，或用户明确要求时启用。

## 二、核心概念

| 概念 | 含义 |
|---|---|
| **体** | 自身可支配的资源：日主、印星、比劫、禄、刃 |
| **用** | 想要获取的对象：财、官、食伤 |
| **做功** | 体与用之间通过刑冲合害墓库等手段发生实际作用，把"用"拿到手的过程 |
| **宾主** | 日主为主，其余三柱为宾；看宾主之间的作用关系 |
| **开库** | 辰戌丑未为四库，逢冲则开库，库中之物才能取出 |
| **象法** | 由干支的字形、物象、方位推导具体人事，非纯五行生克 |

## 三、判法与子平的根本差异

| | 子平（格局／调候） | 盲派 |
|---|---|---|
| 核心问句 | 这个格成不成、层次高不高 | **这个盘有没有"事"在做** |
| 旺衰的地位 | 关键（扶抑的依据） | 次要——不看强弱，看做功有无 |
| 用神概念 | 有明确的用神与忌神 | 谈"用"但不谈扶抑用神 |
| 断事方式 | 由格局与十神推演 | 由体用作用直断具体事项 |
| 强项 | 层次、大方向、一生格局 | 具体事项、应期、事件形态 |

两套判法**结论可能完全不同**：子平说"身弱财旺，财多身弱，富屋贫人"，盲派可能说"财来合我，是财找我，得财不费力"。各有适用场景，不可互证。

## 四、做功的常见形态

| 形态 | 机制 | 象 |
|---|---|---|
| **制用** | 体以官杀或食伤制住财／官 | 靠压制取得 |
| **化用** | 用神生化入体（如官生印、印生身） | 靠转换取得 |
| **合用** | 日主（或其禄刃）与财官天干相合 | 靠关系取得，来得直接 |
| **墓用** | 用神入体之库，逢冲开库取出 | 靠积累后一次性取出 |
| **冲用** | 以冲提取得用神 | 靠变动取得 |

**无做功**的盘，在盲派看来就是"没事可做"——不等于命不好，但难有突出事件。这是与子平"看格局层次"最不一样的结论口吻，表述时要说明这是盲派视角。

## 五、禄、刃、库

- **禄**：日干的临官之地支（甲禄在寅、乙禄在卯……）。禄代表自身的根基与俸禄，**逢冲则根基动摇**，逢合则被人牵住。
- **刃**：日干的帝旺之地支，力量最猛。刃宜有制（官杀）或有所用（合、泄），无制无用的刃是"凶器"。
- **四库**：辰（水）、戌（火）、丑（金）、未（木）为四墓库。库中之物需**逢冲才开**。冲库是盲派断应期的重要抓手——很多"迟来的大事"对应开库之年。

## 六、与子平配合的正确姿势

1. **主线仍用子平定格局与层次**（有典籍依据、可复核）。
2. **盲派仅用于补充具体事件形态与应期**，且明确标注"以下为盲派视角，非典籍判法"。
3. 遇到子平两派都讲不通的盘（如格局不明显、旺衰中和、又无调候之需），可以盲派的"有无做功"作为切入，但必须说明这会偏离典籍路径。

## 七、自检问题

1. 我引用盲派判法时，有没有说明它不是典籍来源？
2. 这个盘的"体"是什么、"用"是什么？中间的功是怎么做的（制／化／合／墓／冲）？
3. 有没有把盲派结论悄悄混进子平叙述里，造成"古法也这么说"的假象？
4. 我是不是因为盲派能讲出一个漂亮的结论就换了主线？换主线的理由写出来了吗？
