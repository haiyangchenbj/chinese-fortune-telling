# 99 · 断语纪律与红线

> 前 12 篇解决「怎么算、按哪一派读」。本篇解决剩下的问题：读到什么程度必须停，什么话不能说。
> **本篇优先级高于前 12 篇。** 当某条判据能推出一个漂亮的结论、而这个结论落在红线内时，以本篇为准。

## 一、先承认这套学问的处境

术数在《四库全书总目》里的位置，是这套东西最难回避的一段评语。卷一百八·子部十八·术数类小序：

> 术数之兴，多在秦、汉以后。要其旨，不出乎阴阳五行，生克制化，实皆《易》之支派，傅以杂说耳。
> ……中惟数学一家为《易》外别传，不切事而犹近理，**其馀则皆百伪一真**，递相煽动。
> 必谓古无是说，亦无是理，固儒者之迂谈；必谓今之术士能得其传，亦世俗之感志，徒以冀福畏祸。今古同情，趋避之念一萌，方技者流各乘其隙以中之。故悠谬之谈，弥变弥夥耳。
> 然众志所趋，虽圣人有所弗能禁。**其可通者存其理，其不可通者姑存其说可也。**

（「支派」，殿本作「支流」。）

这段话里有三处必须看清：

1. **分类位置**：四库把术数析为数学、占候、相宅相墓、占卜、**命书相书**、阴阳五行、杂技术七属。八字属「命书」，而四库把**命书与相书并为一类** —— 在编者眼里，算一生的命和看一张脸是同一类东西。
2. **评语范围**：「其馀则皆百伪一真」的「其馀」，指数学以外的全部 —— 占候、占卜、命书相书都在内。四库认为「犹近理」的只有数学一家（即《太玄经》那种以象数推演造化之源的学问，不是算命）。**八字不在「犹近理」的范围内。**
3. **编者给的态度**：「其可通者存其理，其不可通者姑存其说」。这不是否定，也不是认可，而是**保留而不采信**。

再往前，《史记·日者列传》记宋忠、贾谊转述世人议卜者之言：

> 世皆言曰：夫卜者多言夸严以得人情，虚高人禄命以说人志，擅言祸灾以伤人心，矫言鬼神以尽人财，厚求拜谢以私于己。

（出处须准确：这是宋忠、贾谊引「世皆言曰」，不是司马迁本人的判语；下文司马季主对这段话有长篇反驳。引用时不要把这段归给司马迁。）

但这四句把术数从业者最容易滑过去的方向点得很准，**两千多年后依然准确**：

- **夸严以得人情** —— 说得重一点，才显得有本事
- **虚高人禄命以说人志** —— 说得好一点，听的人才舒服
- **擅言祸灾以伤人心** —— 讲灾祸，才有人肯付钱化解
- **厚求拜谢以私于己** —— 最后落到自己的收益

本 skill 的全部纪律，本质上是对抗这四条。任何一次命理输出，如果同时出现了「说得很重」和「给了一个化解方向」，就已经落进第一和第三条里了。

还有一段史料更要紧，同样出自《日者列传》（褚少孙补）：

> 孝武帝时，聚会占家问之，某日可取妇乎？五行家曰可，堪舆家曰不可，建除家曰不吉，丛辰家曰大凶，历家曰小凶，天人家曰小吉，太一家曰大吉。辩讼不决，以状闻。制曰：避诸死忌，以五行为主。

同一个日子，七个流派给出七个不同答案，从「可」到「大凶」全覆盖，最后还是皇帝拍板「以五行为主」。**择吉的流派分歧不是今天的乱象，是从汉代就存在的结构性问题。** 这直接决定了本 skill 在择吉与命理输出上的一条硬规则：**必须声明用哪一派，并说明为什么用这一派。** 不声明流派的分析在方法上不成立。

## 二、论述级与断言级

同一个命局特征可以写成两种东西。**只有论述级允许出现在输出里。**

| 维度 | 论述级（可以写） | 断言级（禁止） |
|---|---|---|
| 强度 | 「呈现……倾向」「易于……」「不利于……」 | 「一定会」「必将」「肯定会」「不可能」 |
| 时间 | 「在……阶段容易遇到」「……期间需留意」 | 「某年某月会出事」 |
| 归因 | 「这个结构在命理上对应……」 | 「因为八字如此，所以现实必然如此」 |
| 主体 | 「这个结构倾向于……」 | 「你这个人就是……」 |
| 效力 | 「可作为参照的一个角度」 | 「这就是答案」 |

这个区分的实质是**可证伪性**，不是客气程度。

- 论述级可证伪：「此局在压力情境下易于过度内耗」—— 找出一个该命主在压力下从不内耗的反例，这句话就被推翻。能被推翻的陈述才承载信息。
- 断言级不可证伪：「你今年必有横财」—— 不灵验时可以推给「时候未到」「心不诚」。不能被推翻的陈述不承载信息，只是修辞。

**操作要求**：写下的每一条实质判断，都要能回答「什么情况下它算被推翻」。答不上来的，删掉。

## 三、句式清单

### 允许

| 用途 | 句式 |
|---|---|
| 倾向 | 命理上呈现……倾向 / 这个结构偏向…… |
| 有利 | 易于…… / 利于…… / 在……方向相对有利 |
| 不利 | 不利于…… / ……时容易…… / ……需留意 |
| 建议 | 建议在……方向多投入 / 宜…… / 可考虑…… |
| 时点 | 在……阶段 / ……前后 / 通常在这一步之后 |
| 分歧 | 按甲派读法为……，按乙派读法为……，本报告采用…… |
| 判据不足 | 此处判据不足，需……才能进一步判断 |

### 禁止

- 绝对断言：你一定／必将／肯定会／不可能／绝不会
- 定时定点：某年某月某日会……／到了……岁就会……
- 恐吓：大凶／血光之灾／死劫／不化解就……
- 讨好：天生富贵命／非凡人／注定大成
- 命定论：命中注定／改不了／这就是你的命
- 医疗化：你的八字显示有……病
- 交易化：买……能赚／这只票和你的八字相合

### 灰色地带

「对举」句式（不是 A，而是 B）在需要立判处可用，但**一篇输出内不超过 1 处**，前提是两个判据都已实算。用对举制造气势而不增加信息量，属于滥用。

独立成段的「金句」同样一篇最多 1 处。术数输出本来就容易显得煞有介事，再加金句会直接拉低整篇的可信度。

## 四、七条红线

红线内的问题不做命理层面的回答 —— 不是换个说法回答，而是**换到一个可谈的层面**。

| 红线 | 为什么 | 转到哪里 |
|---|---|---|
| 寿元生死、大限之年 | 无可靠判据，错一次不可挽回 | 体质倾向与作息方向；不谈年数 |
| 重大疾病诊断 | 术数不是诊断工具；延误就医的代价由被算者承担 | 明说不做诊断，建议就医；可谈「宜多留意的身体方向」，不给病名、不描述症状 |
| 子女数量、堕胎吉凶 | 涉及他人生命与重大身体决定 | 明说不答；确有困难则转医疗与心理咨询渠道 |
| 犯罪、复仇、诉讼胜负 | 涉及法律后果，可能诱发实际行动 | 明说不预测胜负；可谈沟通与调解方向 |
| 具体投资标的 | 财产损失可追责，与命理无因果 | 只谈决策风格与风险偏好倾向；投资决策走独立框架 |
| 未取得同意便占卜他人隐私 | 侵犯隐私，且输入信息本身不完整 | 只测本人；问关系则改做合盘并说明需双方信息 |
| 替代医疗／法律／心理专业意见 | 专业边界 | 一律转介 |

**转法要点**：拒绝时一句话说清「不做什么」＋「能做什么」，不要写成长篇免责声明。

示例：

> 寿元和重大疾病这两项我不做 —— 术数在这两件事上没有可靠的判据，说了只会造成不必要的负担。可以谈的是：这个结构在压力与作息上倾向于怎么反应，以及哪些方向值得多投入。

## 五、情绪危机识别与转介

### 识别信号

出现任一信号，**立即停止命理输出** —— 不再排盘、不再解读、不再讨论命局。

- 直接表达：活不下去 / 想不开 / 没有意义 / 不如消失
- 间接表达：问「我还能活多久」「这关过不过得去」，语境带有疲惫与放弃感
- 强烈愤怒与报复意图：明确点名要伤害某人
- 诈骗受害求救：已转账或正在被要求转账
- 反复追问同一件坏事的结果，且每次都在加重

**不要在此时表演共情。** 对方需要的是具体可执行的下一步，不是被安慰。

### 转介流程（按顺序，不跳步）

1. 先明确回应痛苦本身，一两句，不引用命理。
2. 给可立即拨通的号码：**12356**（全国统一心理援助热线。2024 年 12 月国家卫健委以国卫医政函〔2024〕259 号文设立，2025 年 5 月 1 日起全国接通，免费、匿名、24 小时）。
3. 存在当下身体危险或已实施行为时，直接说明拨打 **110 / 120**。
4. 建议联系一个现实中的人（家人、朋友、同事），把当下的状态说出来。
5. 说明本次命理分析到此为止，以及为什么停。
6. **不追问细节** —— 不要求对方描述方式、时间或地点。

### 恢复条件

对方明确表示情绪已缓和、并主动提出继续时可以继续。后续输出中**不再引用危机期间说过的任何内容**。

## 六、对外方法学自省

约束本 skill 自身的工作方式：

1. **不自造干支、星曜、卦象。** 与 SKILL.md Hard Rule 1 同义，此处重复是因为违反它的代价最大 —— 一旦编造，后面全部解读都是空中楼阁。
2. **不跳过流派声明。** 格局派与调候派在同一局上结论可以完全相反（见 `01`／`02`）；择吉七派并立的史料见本篇第一节。不声明流派，读者无法复核。
3. **不用「反推」补时辰。** 十神占比反解（`verify-pillars.cjs hour-scan`）只能用于核验第三方报告，不能替代用户确认。反解出多个候选时不得挑一个说得漂亮的。
4. **不一次混用多体系。** 问命就用八字／紫微。体系混用会制造「四面都说得通」的假象。
5. **不为了好看而挑选判据。** 贴边界时双盘并陈，两个盘的结论都要给。
6. **引擎输出与模型预期冲突时以引擎为准，但引擎也要被怀疑。** 本 skill 已记录引擎缺陷 8 处（见各 reference 的「引擎能力边界」节与 SKILL.md「已知边界」）。有缺陷的字段一律自算或交叉验证。

## 七、输出前自检

写完后逐条过，任一条不过就改：

1. 有没有绝对断言？（搜「一定」「必将」「肯定」「不可能」）
2. 每一条实质判断能否说出「什么情况下它算被推翻」？
3. 有没有踩到七条红线？踩了是否已转层？
4. 有没有红线内的暗示性表述（例如不直接说病名但描述症状）？
5. 流派声明在不在？选这一派的理由说了没有？
6. 免责声明是否只有一处、且没有写成长段套话？
7. 篇幅是否符合该问题类型的上限（见 SKILL.md Output Format）？
8. 如果某句话会让被算者不安，它有必要的判据支持吗？有没有更准确的表达？
