# 06 · 梅花易数

主线典籍：《梅花易数》（托名宋·邵雍／邵康节）。实际成书年代学界有争议（宋说与明说并存），但体系归《四库》"占卜之属"的占筮一脉。
用途：**快速看当下气机与变化趋势**，尤其适合用户随口一问、或无生辰可依的场景。

## 一、起卦法

| 法 | 做法 | 适用 |
|---|---|---|
| 先天数起卦 | 报数／日期数取上下卦与动爻 | 最常用，可复现 |
| 时间起卦 | 年＋月＋日数取上卦，加时数取下卦，总数取动爻 | 无数据时的默认 |
| 方位起卦 | 上下卦取自方位 | 与空间相关之事 |
| 外应起卦 | 见物、闻声、遇事即起 | 临机而占，主观性最大 |

脚本：`node meihua.js`（时间起卦）、`node meihua.js 3 5 2`（报数）、`node meihua.js 东 南`（方位）。

## 二、体用：判断的核心

**动爻所在的卦为「用」，另一卦为「体」。**
- 动爻在下卦 → 下卦为用，上卦为体
- 动爻在上卦 → 上卦为用，下卦为体

| 体用关系 | 判语 | 意味 |
|---|---|---|
| 用生体 | **吉** | 外来的助力，事顺 |
| 体用比和 | 顺 | 同气相求，平稳可成 |
| 体克用 | 可成但费力 | 能拿下来，需投入 |
| 体生用 | 耗 | 出力却外泄，费力不讨好 |
| 用克体 | **凶** | 受制于人／事，宜止 |

## 三、体宜旺相

**这是脚本没做、必须人工补的一步。** 体卦的旺衰由**月令**决定：

- 体卦五行当令（旺相）→ 承受力强，凶象可减
- 体卦休囚死 → 即便用生体，力量也弱，吉象打折；若用克体则加重

处置：先看月令对体卦的生克，再看体用关系。**只看体用生克不看旺衰，是最常见的梅花误断。**

## 四、三卦层递

| 卦 | 看什么 |
|---|---|
| 本卦（体用） | 当下的格局与双方关系 |
| **互卦** | 事情的**中间过程**、内情、隐情 |
| **变卦** | 事情的**结果走向** |

互卦由本卦二三四爻为下卦、三四五爻为上卦组成。变卦由动爻变后得出。

判读次序：本卦定关系 → 互卦看过程 → 变卦看结局。三者结论一致则断得实；不一致时**以变卦为主**（结局优先），并说明过程中有转折。

## 五、三要十应

《梅花易数》主张以外应参断，但这是全体系里**最主观**的部分，处置纪律如下。

**三要**：耳（听）、目（见）、心（感）——起卦当下的直接感知。

**十应**（正应、互应、变应、方应、日应、刻应、外应、天时应、地理应、人事应）：以起卦时周遭的人、事、物、方位、天气为参证。

**引用纪律**：
1. 外应只作**辅证**，不作主判据。主判据永远是体用生克加月令旺衰。
2. 只有一个外应时，权重极低，不得据此翻转体用的结论。
3. 输出的外应部分必须让用户知道这是主观参证，不是可复核的推导。
4. 用户没有提供现场情境时，**不虚构外应**。

## 六、与六爻的分工

| 场景 | 选哪个 |
|---|---|
| 单件具体事、要断应期 | 六爻纳甲（体系严密，可复核） |
| 随口一问、无生辰、看看趋向 | 梅花易数 |
| 同一件事需要交叉验证 | 两者都起，比较结论。冲突时以六爻为主，并说明分歧 |

## 七、自检问题

1. 动爻在哪一卦？体用分对了吗？
2. 体卦的月令旺衰是什么状态？我补了这一步没有？
3. 互卦与变卦我看了吗？三者结论一致吗？不一致时我以哪个为准、说明了没有？
4. 我引用的外应是用户给的实况，还是我自己编的？
5. 结论是不是只用一句"用生体，吉"就收口了？有没有落到"吉到什么程度、何时见、要注意什么"？
