# 09 · 七政四余

主线典籍：《果老星宗》（托名唐·张果老）、《星学大成》（明·万民英，与《三命通会》同一作者）、《乾元秘旨》（清）。《星平会海》（明）兼论七政四余与子平，可作对读。
用途：星命一路的推演，与子平互为参证。

## ⚠ 先读：本 skill 无七政四余引擎

七政四余的推演依赖**真实天象位置**——日月五星在黄道上的实际度数、二十八宿的入宿度、四余（虚星）的推算周期。这需要一套历表或天文算法，`scripts/` 里没有。

因此当前口径：
- **可以讲清体系结构、判读逻辑、与西方古典占星的同源关系**，用于解答用户对星命本身的问题。
- **可以评估第三方七政四余结果的合理性**（如四余周期、星曜不可能的位置、宫位起法是否有误）。
- **不自行推算星历，不给出未经实算的七政四余结论。**
- 需要实际星盘时，导流到有历表能力的工具，或说明本 skill 不覆盖该步骤。

## 一、体系构成

**七政**：日、月、水星、金星、火星、木星、土星。
**四余**：罗睺、计都、紫气、月孛——四个虚星。

四余的来源值得说明：它们是**由交点与远地点推得的虚设点**（罗睺、计都为月亮的升／降交点，紫气、月孛为周期性的推算虚星），并不是实际天体。这一点在判断时很重要：四余的"强弱"是推算出来的，不是观测得到的。

**二十八宿**是七政四余赖以定位的坐标框架（角亢氐房心尾箕……），星曜入宿决定其落宫与得失。

## 三、与西方古典占星同源（重要）

七政四余与西方古典占星**共享同一个希腊化源头**：希腊化时期的占星学（Ptolemy、Dorotheus、Vettius Valens 一系）随佛教与天文历算一同传入中土，在唐代形成星命一路，与本土的干支禄命并行发展。

证据性的重合：
- 十二宫的分野与排序基本一致
- 星曜的吉凶属性一致（木星吉、土星凶、火金水各有性）
- 都有"庙旺落陷"的概念
- 都以真实天象位置为推演基础（这正是与子平的根本不同）

**实务含义**：这两套体系可以互相参证，但**不能混算**——宫位起法（上升点 vs 命宫）和坐标系（回归黄道 vs 二十八宿）不同，数值不可互换。用户同时问两边时，分开陈述。

## 四、判读要点（实算之后）

1. **命宫与身宫**：命宫定自身，身宫定一生着力处。
2. **星曜入宫**：各政落入何宫，决定该宫领域的强弱。
3. **庙旺落陷**：星曜在其所居宿度的得失状态——入庙为得地，落陷为失力。
4. **星曜关系**：四合（合、冲、三合、六合）决定星与星之间的助与伤。
5. **四余的作用**：多用于补足隐性因素；因是虚星，判语应比七政更保守。

## 五、与子平的分工

| | 子平八字 | 七政四余 |
|---|---|---|
| 基础 | 干支五行生克 | 真实天象位置 |
| 十二宫分野 | 无（用十神、宫位另论） | 有，且与西方占星对应 |
| 强项 | 一生格局层次、运势大方向 | 各生活领域的分布、与外部时点的呼应 |
| 本 skill 支持 | 完整（有引擎） | 仅理法，无实算 |

用户同时要两边时，**先出八字**（可复核），七政四余部分说明需要外部的星历工具，不硬凑。

## 六、自检问题

1. 我是不是在没有星历数据的情况下编了星曜位置？（绝对不允许）
2. 涉及四余时，我说明它们是虚星、不是实际天体了吗？
3. 我有没有把西方的宫位制套进七政四余的宫位，或者反过来？
4. 疾厄宫、福德宫的内容是不是越界成了疾病诊断或寿元判断？
