# 07 · 奇门遁甲

主线典籍：《御定奇门宝鉴》（清，收入《四库全书》阴阳五行之属）、《烟波钓叟歌》（传宋·赵普）、《遁甲演义》（明，四库阴阳五行之属）。
用途：**择时、择方、看某件事的推进窗口**。不宜用来断一生格局。

## ⚠ 先读：脚本的可用边界

`scripts/engine/qimen.js` 输出的是**部分盘面**，使用前必须知道缺什么：

| 引擎有 | 引擎无 |
|---|---|
| 阴阳遁（按冬至／夏至分界） | **局数**（一至九局，由节气三元定） |
| 值符、值使 | **神盘**（八神落宫） |
| 九宫排布，每宫给出**星＋门** | **三奇六仪落宫**（乙丙丁、戊己庚辛壬癸） |
| 时辰干支 | 马星、空亡、门迫、击刑等格局标记 |

因此：**本 skill 不做完整的奇门格局判断**。引擎能给的是"某方位某时辰的星门组合"，这个层面的择时择方是可用的；凡涉及三奇得使、吉格凶格、神盘吉凶的判断，因缺盘面数据，**一律不给结论**，或明确标注为"未完成起局，不足以断"。

## 二、结构：四盘

| 盘 | 内容 | 说明 |
|---|---|---|
| 地盘 | 三奇六仪固定按局数排布 | 基础，不动 |
| 天盘 | 九星随值符转动 | 主"天时" |
| 人盘 | **八门** | 主"人事"，实用价值最高 |
| 神盘 | 八神 | 主隐性力量与氛围 |

**阳遁**：冬至后，六仪顺布、三奇逆布。**阴遁**：夏至后，六仪逆布、三奇顺布。

## 三、八门（最实用的一层）

| 门 | 吉凶 | 宜 |
|---|---|---|
| 开 | 吉（三吉门） | 开业、远行、求见贵人 |
| 休 | 吉（三吉门） | 休息、婚娶、谋求 |
| 生 | 吉（三吉门） | 求财、经营、置业、疗养 |
| 伤 | 凶 | 用兵、讨债、催讨；不宜喜庆 |
| 杜 | 中 | 闭塞、藏匿；宜避不宜进 |
| 景 | 中 | 文书、宴乐、宣传；宜见不宜密 |
| 死 | 凶 | 丧葬、刑罚；诸事不宜 |
| 惊 | 凶 | 惊恐、口舌、诉讼；宜谨慎 |

**门迫**（门克宫）、**门制**（宫克门）、**门生宫**、**宫生门**，是判断门力真假的关键：得门而门迫，吉门亦减力。

## 四、九星与八神

**九星**：天蓬（水）、天任（土）、天冲（木）、天辅（木）、天英（火）、天芮（土）、天柱（金）、天心（金）、天禽（土，寄坤或中宫）。

星分吉凶与旺衰：天辅、天心、天禽为吉；天蓬、天芮、天柱偏凶。星力随月令旺衰而变。

**八神**（随值符起，阳遁顺、阴遁逆）：值符 → 螣蛇 → 太阴 → 六合 → 白虎（勾陈）→ 玄武（朱雀）→ 九地 → 九天。值符为最尊，六合主和，白虎主凶，玄主昏昧。

> 八神落宫需神盘，引擎未提供。涉及八神的判断在本 skill 中不输出。

## 五、值符与值使

- **值符**：随时干，是当期主事的天盘星。值符所到之宫为"主"。
- **值使**：随时宫，是人盘门的主事者。值使所到之宫为"事"之所在。

看吉利与否，先看**值符与值使所在宫的门、星关系**，再看所问方位的门星。

## 六、择时择方的用法

引擎能给出生效的盘面时，可按下列顺序用：

1. 明确**要问什么方位／什么时刻**（这是奇门的问题形式，不问就别起局）。
2. 跑 `node qimen.js <日期> <时辰数字>`，取该宫的门与星。
3. 门为三吉门（开休生）且不受门迫 → 可用；门为凶门 → 避。
4. 星旺相者加权，星休囚者减权。
5. 结论口径：给"此方位此时辰可用于推进／不宜推进"，**不给"必成／必败"**。

择吉类问题若只是挑日子，优先用 `references/11-zeri.md` 的协纪辨方书体系（有引擎支持）；奇门用于"某具体时点往某方向办事"这类更细的判断。

## 七、自检问题

1. 我是不是在盘面不完整（无神盘、无三奇六仪）的情况下就给了格局吉凶结论？
2. 我给出的是"门星组合判断"，还是越界讲成了吉格凶格？
3. 门力是否受门迫／门制影响？我看了宫与门的关系没有？
4. 我所问之事的方位和时点是否明确？没明确就该先问用户，而不是随便起一局。
