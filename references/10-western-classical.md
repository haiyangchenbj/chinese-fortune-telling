# 10 · 西方古典占星

主线典籍：Ptolemy《Tetrabiblos》（《四书》）、Dorotheus《Carmen Astrologicum》、Vettius Valens《Anthology》（希腊化时期）；Abu Ma'shar、Al-Biruni（阿拉伯时期）；Guido Bonatti《Liber Astronomiae》（中世纪）；**William Lilly《Christian Astrology》（1647）**——近代最系统的英文总结。
用途：性格底色、领域强弱、事件择时。**与七政四余同源**，见 `09-qizheng-siyu.md`。

## ⚠ 先读：本 skill 无西方星盘引擎

推算星盘需要天文历表（行星黄经、宫位计算、上升点）。`scripts/` 内没有该能力。

因此：**可以讲清古典占星的判读体系与流派分野、评估第三方星盘结论的合规性，但不自行计算星盘。** 需要实盘时说明本 skill 不覆盖该步骤。

## 一、最重要的一条：古典 vs 现代心理占星

这是"经典"与"娱乐化"在西方占星里的分野线。**本 skill 一律采古典口径。**

| | 古典占星（本 skill 采用） | 现代心理占星（不采用） |
|---|---|---|
| 行星 | **只用七政**：日月水金火木土 | 加入天王、海王、冥王（1781／1846／1930 年才发现，不属古典体系） |
| 吉凶 | 行星**有天然吉凶**：木星为吉、土星为凶、火星凶中有用 | 行星中性化，只讲"能量的不同表达" |
| 目标 | **断世俗事**：财富、婚姻、事业、地位、寿元 | 讲心理成长、自我觉察、原型象征 |
| 预测 | 有明确技术：法达星限、太阳返照、主限推进、小限 | 多回避明确预测 |
| 判语 | 有吉凶、有成败、可验证 | 优点与缺点成对出现，无法证伪 |
| 代表 | Lilly、Bonatti、Ptolemy | 20 世纪的荣格派一系 |

**为什么这条线重要**：现代心理占星的判语几乎无法证伪（"你既有 A 的一面，也有 B 的一面"），而古典占星给出的是可检验的判断。用户若要"经典"而非"娱乐"，分野就在这里。

**明确排除**：报纸杂志式的太阳星座运势（sun-sign horoscope）——它把全人类按出生月份分成十二种，连出生年份与时辰都不用，既非古典也非现代占星，是独立的通俗读物体裁。本 skill 不做。

## 二、基本构件

**七政与其吉凶属性**

| 行星 | 古典属性 | 主管 |
|---|---|---|
| 太阳 | 中性偏吉 | 生命、地位、父 |
| 月亮 | 中性 | 情绪、身体、母、变动 |
| 水星 | 中性（随所伴） | 思维、文书、交易 |
| 金星 | **吉** | 情感、审美、财富 |
| 火星 | **凶**（但为用则刚毅） | 冲突、勇气、手术、争斗 |
| 木星 | **吉** | 扩张、贵人、财富、法度 |
| 土星 | **凶** | 限制、延迟、损失、结构 |

**十二星座**：牡羊（火）金牛（土）双子（风）巨蟹（水）狮子（火）处女（土）天秤（风）天蝎（水）射手（火）摩羯（土）水瓶（风）双鱼（水）。

**十二宫**：与七政四余的十二宫一一对应（见 `09` 表）。

**庙旺落陷**（essential dignities）：
- **庙**（domicile）：行星在自己的宫
- **旺**（exaltation）：行星在其曜升位
- **陷**（detriment）：在庙的对宫
- **落**（fall）：在旺的对宫

**相位**（aspects）：合（0°）、六合（60°）、刑（90°）、三合（120°）、冲（180°）。古法另重 150°（梅花相位，用于特殊判法）。

## 三、判读顺序

1. **定上升与宫位**（需实盘）。
2. **看上升主星**（chart ruler）的状态——落宫、庙旺落陷、相位。
3. **看宫主星**（lord of the house）：每一个所问领域的强弱看其宫主星。
4. **看相位与接纳**（reception）：两星互容则相互成就，相刑相冲则相互牵制。
5. **看阿拉伯点**（lots）：尤以幸运点（Lot of Fortune）为要。
6. **走时间技术**：
   - **法达星限**（Firdaria）：按行星长周期分段，定人生阶段的主星
   - **小限**（profection）：一年一宫，定年度主题
   - **太阳返照**（solar return）：每年生日时点的盘，定该年运势
   - **主限推进**（primary directions）：古典占星里最精确的预测技术，也最复杂

## 四、时限技术的时间粒度

| 技术 | 粒度 | 用途 |
|---|---|---|
| 法达星限 | 数年至十余年 | 人生大阶段的主星与主题 |
| 主限推进 | 精确到月／日 | 具体事件时点 |
| 太阳返照 | 一年 | 该年运势 |
| 小限 | 一年（一宫） | 年度主题 |

这四项与八字的**大运／流年**功能对位，可以并列陈述，但**不可互相换算或加权**。

## 五、与七政四余的互参

两者同源，十二宫对应，所以：
- **可以并列陈述**，让用户看到两个体系在同一领域的共识与分歧。
- **不可数值互换**：宫位起法（上升点 vs 命宫）与黄道系统不同。
- **不可当作独立验证**：同源体系的一致性不构成独立证据。这一点必须向用户说明，否则会把"同一源头推出两遍"误当成"两个体系互相印证"。

## 六、自检问题

1. 我有没有用三王星（天王、海王、冥王）？用了就偏离古典口径了。
2. 我给出的判语是可证伪的，还是"你既有这一面也有那一面"式的万能话？
3. 我是不是把太阳星座运势当成了古典占星的分析？
4. 涉及西方占星与七政四余时，我说明了两者同源、因此不构成独立互证了吗？
5. 星盘数据是从哪里来的？如果没有实盘，我是不是编了一个？
