# 08 · 大六壬

主线典籍：《六壬大全》（收入《四库全书》占卜之属）、《毕法赋》（宋·凌福之）、《大六壬指南》（明·陈公献）、《大六壬心镜》、《秘藏大六壬大全》。
用途：**单件大事的细节推演**——过程、各方动向、成败与应期。三式（太乙、奇门、六壬）中六壬专主人事。

## ⚠ 先读：本 skill 无大六壬引擎

与六爻、梅花、奇门不同，**本 skill 不提供大六壬的自动起课脚本**。原因是九宗门（尤其涉害、昴星、别责）的取用规则环节多、易错，仓促实现会产出看似合理实则错误的课体，比不做更危险。

因此当前口径：
- **可以讲解大六壬的理法与判读逻辑**，用于解答用户对六壬本身的问题。
- **可以复核第三方给出的课体是否合规**（四课三传有无明显错误）。
- **需要实际起课时，按下方步骤手工起**，并在输出中说明"课体系手工推得"。
- **不给未经手工起课的六壬结论。**

## 一、基本概念

| 概念 | 含义 |
|---|---|
| **月将** | 太阳过宫所在，按中气取（雨水后亥将、春分后戌将……） |
| **占时** | 问事时辰的地支 |
| **天地盘** | 月将加占时的地支之上，顺布十二支，得天盘；地盘固定十二支 |
| **四课** | 由日干与日支起，反映我与事、彼与此四层关系 |
| **三传** | 发用（初传）、中传、末传——事情的起因、经过、结果 |
| **十二天将** | 贵人、螣蛇、朱雀、六合、勾陈、青龙、天空、白虎、太常、玄武、太阴、天后 |

## 二、起课步骤

1. **取月将**：按起课日所在中气定月将。
2. **月将加时**：把月将的地支放在占时的地支位置，顺布十二支于十二宫，得天盘。地盘不动（子居正北，顺时针）。
3. **起四课**：第一课为日干寄宫之上神（干阳）；第二课由第一课的地盘位再取上神；第三课为日支本身之上神；第四课由第三课的地盘位再取上神。
4. **发三传**：按九宗门取初传，再依"中传取初传之上神、末传取中传之上神"顺推（伏吟、返吟等特例另有法）。
5. **布十二天将**：以贵人起，昼贵／夜贵按时辰分，顺布十二将。

## 三、九宗门（取初传的法则）

初传的取法按固定优先级，逐条试，命中即止：

| 序 | 门 | 触发条件 |
|---|---|---|
| 1 | **贼克** | 四课中有下贼上（克）者取之；无则取上克下者 |
| 2 | **比用** | 上下克不止一处，取与日干同阴阳者 |
| 3 | **涉害** | 比用仍不能定，比较各课受克深浅，取深者 |
| 4 | **遥克** | 四课无上下克，取四课上神克日干者（蒿矢）；无则取日干克上神者（弹射） |
| 5 | **昴星** | 无遥克时，阳日取地盘酉位上神，阴日取天盘酉下神 |
| 6 | **别责** | 四课不全（只有三课）时用之 |
| 7 | **八专** | 日干日支同位（干支同柱）时用之 |
| 8 | **伏吟** | 月将与占时相同，天地盘重合 |
| 9 | **返吟** | 月将与占时相冲，天地盘全冲 |

**涉害、昴星、别责三门最容易出分歧**，不同传本在细节上有出入。手工起课时应说明依据的是哪一系（本 skill 采《大六壬指南》一系口吻），并提示存在版本差异。

## 四、判读要点

1. **日干为我**：三传与日干的关系定自身处境。
2. **三传次第**：初传为起因／当前，中传为过程，末传为结果。三传相生为顺，相克为阻。
3. **课体吉凶**：课体名称本身即含判语（如"三光""六仪"为吉课，"返吟""刑冲"为凶课）。
4. **十二天将**：天将所临之宫决定该方人事的性质。贵人、六合、青龙、太常偏吉；螣蛇、天空、白虎、玄武偏凶。
5. **应期**：多以三传地支所值之年月日，或日干的长生、临官之时为应。

## 五、与六爻、奇门的分工

| | 大六壬 | 六爻 | 奇门 |
|---|---|---|---|
| 强项 | 细节丰富、过程脉络清楚 | 起课简便、用神明确 | 时空方位 |
| 弱项 | 起课繁复、规则分歧多 | 细节不如六壬 | 盘面复杂、本 skill 覆盖有限 |
| 何时用 | 大事、需要看过程与各方动向 | 常规问事、要应期 | 择时择方 |

同一件事不要三式齐上——**起课越少，判断越清**。用户在无特别理由时，问事默认用六爻。

## 六、自检问题

1. 我是否在不起课的情况下就给出了六壬结论？（不允许）
2. 月将取得对吗？是按中气而非节气取的？
3. 初传的取法走的是九宗门里的哪一门？中间几门为什么被排除？
4. 我说明依据的是哪一系传本了吗？涉及涉害、昴星、别责时有没有提示版本差异？
5. 三传的次第关系看清楚了吗？还是只看了一个初传就下结论？
